## What changed

### Grid

- Square cards with images filling their frames, responsive side margins, and more spacing.
- Original colors with a slight saturation/contrast adjustment instead of strong grayscale.
- Empty-looking starting-state thumbnails replaced with actual interaction captures. Brush captures exclude the surrounding page whitespace; the video thumbnail uses a frame from its bundled clip.

### Individual projects

- Each detail view initially shows a static preview. Clicking anywhere on it, including the centered play glyph, replaces it with the sketch in the same frame.
- A subtle close glyph at the upper right appears on hover or keyboard focus. It stops the sketch and restores the preview. Touch devices keep this control visible.
- Switching projects or leaving the detail view removes the running iframe. There is no separate sketch running at the bottom of the notes.
- All thirteen sketches use their iframe viewport for canvas dimensions. Shared resize behavior preserves drawing marks; sketches with special image buffers retain their own resize handling.
- The reveal-image sketch hides its offscreen mask canvas and resizes its mask/image buffers with the viewport.
- The video sketch mutes playback, uses its bundled clip for the initial canvas background, and uses the remote historical clip when available. Dragging can use the local clip as a fallback.
- Detail images have separate 1600 × 1600 captures rendered at 2× density. Grid thumbnails remain separate assets.

### Source and layout polish

- The preview, heading/details, notes, and code panel share a centered width and aligned edges.
- The original Markdown code excerpts actually ended mid-line. Each project's `source:` now points to its real runnable JavaScript; the detail renderer substitutes the complete source for the excerpt.
- Code panels have bounded height and automatic scrolling in both directions, plus keyboard focus for scrolling.
- A top-right copy glyph appears on hover or focus. It copies the complete source and briefly shows a checkmark. Touch devices keep it visible.
- Failed automatic copying selects the code and announces a manual-copy fallback.
- Summary removal preserves whitespace inside source code; splitting and rejoining all paragraphs had altered blank-line whitespace.
